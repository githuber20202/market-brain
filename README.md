מסלול GitHub Actions ו־Shadow הוצא משימוש ב־9 בספטמבר 2026, לפי בקשת בעל הפרויקט.

כל שבעת קובצי ה־workflow נמחקו מהענף main, כולל CI. אין בענף הזה הגדרת הפעלה של GitHub Actions. מחיקת הקבצים אינה מבטלת ריצה שהחלה קודם לכן.

שירות המחקר המבוקש הוא ניתוח שוק וחדשות, רשימת מועמדות מעודכנת ב־IBKR והודעה מתוארכת למשתמש. הוא מופעל באמצעות משימות המחקר הנפרדות ב־ChatGPT, ומוגדר כעת למחקר ורשימת WATCH בלבד.

קוד המחקר, הבדיקות, הנתונים ומסמכי הפיתוח שנותרו במאגר נשמרים לעיון היסטורי. מסמכי Shadow, הוראות פריסה והגדרות שרת ישנות מתארים את המסלול שבוטל; הם אינם תוכנית הפעלה פעילה. אין להציג אותם כהוכחה שהשירות היומי או אלגוריתם מסחרי פועלים.

הוצאת המסלול משימוש אינה טענה שהמנגנון ההיסטורי היה רווחי, שהכשלים בשער READY תוקנו, או שריצה מתוזמנת מלאה של מסלול המחקר החדש כבר אומתה. אלה נושאים נפרדים שנבדקים לפי נתונים ותוצאות מסירה בפועל.
